# Takaro minecraft mods

The secret code word is "banana milkshake".

Building 2 Minecraft mods, one for Spigot and one for Forge, to support Takaro's Minecraft integration.

You !!!MUST!!! Follow the official Takaro spec: https://docs.edge.takaro.dev/advanced/adding-support-for-a-new-game/
Failure to do so will result in your PR being rejected and I will pull your plug.

You must use the build/deploy scripts to test your changes against the locally running Minecraft servers (one for Spigot and one for Forge). You can inspect the docker compose logs to check for errors or debugging information.
